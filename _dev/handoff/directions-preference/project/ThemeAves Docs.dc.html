01 · REQUIREMENTS

Server requirements

SlotDesk AI runs on a standard PHP stack. Shared hosting works for a single location; a small VPS is recommended for multi-branch setups.

PHP8.1 or newer
databaseMySQL 8 / MariaDB 10.4+
extensionscURL, mbstring, PDO, OpenSSL
whatsappWhatsApp Business API number
02 · INSTALLATION

Install in five steps

Upload the package, point a database at it, and run the guided installer. Most setups are live in under twenty minutes.

$ unzip slotdesk-ai.zip -d /var/www/slotdesk
$ cd /var/www/slotdesk && cp .env.example .env
$ php artisan key:generate
$ php artisan migrate --seed
# open https://your-server/install to finish
03 · CONNECT WHATSAPP

Connect your number

Paste your WhatsApp Business API token and phone-number ID into Settings → Channels, then set your webhook URL. SlotDesk verifies the connection and sends a test message.

Webhook URL
https://your-server/webhooks/whatsapp
04 · CONFIGURATION

Services & staff

Define the services you offer, their durations, and which staff perform them. SlotDesk only offers slots that satisfy every rule you set.

05 · AVAILABILITY RULES

Buffers, lead times, blackouts

Set a buffer between appointments, a minimum booking lead time, and blackout dates per service. The rules engine applies these before any slot is ever offered.

06 · UPDATING

Staying current

Every release is dated in the changelog. Back up your database, replace the package, and run php artisan migrate. No data is lost between versions.

07 · BACKUPS

Backups are yours

Because SlotDesk runs on your server, backups follow your own routine — a nightly MySQL dump plus the uploads folder is enough to restore anywhere.
